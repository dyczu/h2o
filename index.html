Brak konfiguracji GitHub
⚙️ Konfiguracja repozytorium
Token jest przechowywany tylko lokalnie w Twojej przeglądarce.
🔧 Jak to działa?
1
Aktywujesz pelerynę w panelu → panel commituje plik capes/TwójNick.png do Twojego repo na GitHubie przez API
2
Dodajesz wpis do pliku hosts, który przekierowuje OptiFine na Twój GitHub Pages
3
OptiFine odpytuje s.optifine.net/capes/TwójNick.png → trafia na Twoje repo → pobiera właściwy plik
📄 Wpis do pliku hosts
Uruchom Notatnik jako administrator i otwórz plik C:\Windows\System32\drivers\etc\hosts, dodaj na końcu:
Najpierw skonfiguruj GitHub aby zobaczyć wpis hosts →
Po dodaniu wpisu uruchom: ipconfig /flushdns w CMD i zrestartuj Minecrafta.
